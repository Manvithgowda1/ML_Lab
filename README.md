# Machine Learning Lab – P21CS704

A collection of Python implementations of fundamental Machine Learning algorithms as part of the **Machine Learning (Integrated) – P21CS704** laboratory course (Semester VII).

This repository contains practical implementations of supervised learning, classification, regression, ensemble learning, and concept learning algorithms using Python and Scikit-learn.

## 📚 List of Experiments

| No. | Experiment | Dataset / Application |
|:---:|---|---|
| 01 | FIND-S Algorithm | EnjoySport Dataset |
| 02 | Candidate Elimination Algorithm | EnjoySport Dataset |
| 03 | Decision Tree – ID3 Algorithm | Play Tennis Dataset |
| 04 | Decision Tree – CART Algorithm | Play Tennis Dataset |
| 05 | Decision Tree Regression | Play Tennis Regression Dataset |
| 06 | Perceptron Algorithm | AND Logic Gate |
| 07 | Naive Bayes Classifier | Iris Dataset |
| 08 | Naive Bayes for Text Classification | SMS Spam Dataset |
| 09 | Random Forest Classification | Iris Dataset |
| 10 | AdaBoost Ensemble Learning | Iris Dataset |

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Libraries:**
  - NumPy – Numerical computations
  - Pandas – Data manipulation and analysis
  - Scikit-learn – Machine Learning algorithms and model evaluation
  - Matplotlib – Data visualization
- **Environment:** Jupyter Notebook

## 📂 Datasets

The experiments use the following datasets:

- **EnjoySport Dataset:** Used for FIND-S and Candidate Elimination algorithms.
- **Play Tennis Dataset:** Used for ID3 and CART decision tree classification.
- **Play Tennis Regression Dataset:** Used for Decision Tree Regression.
- **Iris Dataset:** Used for Naive Bayes, Random Forest, and AdaBoost classification.
- **SMS Spam Collection Dataset:** Used for text classification into spam and ham messages.
